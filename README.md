# TODO-project (Веб-сервер планировщика задач)

# Описание проекта

Данный проект представляет собой веб-сервер, реализующий функциональность простого TODO-списка (планировщика задач). Веб-приложение позволяет пользователям управлять задачами, включая такие операции, как добавление новых задач, просмотр существующих, изменение параметров задач и их удаление. Основные особенности включают возможность повторения задач согласно заданным правилам, хранение задач в базе данных SQLite и предоставление RESTful API для взаимодействия с клиентом.

# Инструкция по запуску кода локально

1. Склонируйте репозиторий на свою машину с помощью Git:

git clone https://github.com/sam39rus/go_final_project.git

2. Установите необходимые зависимости (они уже прописаны в файлах проекта):

go mod download

3. Запустите сервер:

go run main.go

4. Проверьте доступность интерфейса браузера по адресу:

http://localhost:7540/

5. По умолчанию сервер слушает порт 7540. Порт можно задать через переменную среды TODO_PORT.

# Инструкция по запуску тестов

Перед началом тестирования убедитесь, что сервер запущен. Затем перейдите в каталог тестов и выполните команду:go test -run TestAll ./tests
Эта команда проведет все доступные тесты, показывая результаты прохождения тестов.
